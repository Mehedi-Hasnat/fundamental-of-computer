Introduction to Web Development

Web development is the process of creating and maintaining websites using technologies such as HTML and CSS. HTML is responsible for structuring the content of a webpage, while CSS is used to design and style the layout. Together, they help in building a visually appealing and well-organized website.

A good website should be simple, clean, and easy to understand. Proper use of colors, spacing, and alignment ensures that users can read and navigate the content easily. In this assignment, a minimal and structured approach has been followed to maintain clarity and professionalism.

Procedure of Creating This Website

The first step was to create the basic structure using HTML. A header section was added at the top with a light gray background and centered white text to highlight the title "Assignment Submission".

After that, an information box was created to display important details such as department, course, student name, and merit position. The box was styled with a black background, white bold text, and rounded borders to make it visually attractive and clearly visible.

Next, additional sections were added to include detailed explanations about web development and the design process. CSS was used to apply spacing, alignment, and background styling. Proper margins, padding, and font choices were used to ensure the layout remains clean and readable.

Importance of Proper Presentation

Presentation plays a vital role in both web development and academic assignments. A well- organized layout makes the content more engaging and easier to understand. Clean design, consistent formatting, and proper alignment improve the overall quality of the work.

In this assignment, extra content has been added to make the document more informative and suitable for printing as a hard copy. This ensures that the assignment looks complete, detailed, and professionally presented when submitted.

Overall, this project demonstrates the basic use of HTML and CSS while focusing on structure, styling, and content organization to create an effective landing page.
